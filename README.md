# TicTacToe Game
A mobile App Implementing an Interactive UI, coupled with seamless navigations and Firebase for backend and multiplayer feature.

# 🛠️ Tech Stack Used 

- **Framework**: Flutter
- **Language**: Dart
- **UI Components**: Custom Flutter widgets
- **Dependencies**: flutter pub dev

 ## User Experience
 **Responsive Design**: Clean, modern UI with smooth navigation
 **State Persistence**
